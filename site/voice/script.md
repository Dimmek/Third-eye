# Тексты для озвучки «Дорога к себе»

Один файл = один ключ: `voice/<ключ>.mp3`. Паузы между фразами ~1 с. Темп медленный, голос мягкий, без «дикторской» подачи.

Папки: `f/` — женский голос, `m/` — мужской. Генерация: `python3 gen_elevenlabs.py f` и `... m`.

## cocoon

Посмотрите на золотую сферу.

Это ваша защитная сфера. Вы внутри неё.

Смотрите на неё спокойно, мягким взглядом.

Из земли через стопы в вас поднимается энергия.

Она идёт вверх по телу, через каждую чакру.

Корень. Живот. Солнечное сплетение. Сердце. Горло. Межбровье. Макушка.

Энергия выходит через макушку вверх, в космос.

И там рассеивается, как свет звёзд.

Теперь из космоса к вам льётся золотой свет.

Через макушку он опускается вниз, до самого копчика.

От копчика свет поднимается вверх, к сердцу.

Из сердца он расходится во все стороны и наполняет золотую сферу.

С каждым выдохом сфера светится ярче.

Она мягко вибрирует и защищает вас.
