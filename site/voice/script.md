# Тексты для озвучки «Дорога к себе»

Один файл = один ключ: `voice/<ключ>.mp3`. Паузы между фразами ~1 с. Темп медленный, голос мягкий, без «дикторской» подачи.

Папки: `f/` — женский голос, `m/` — мужской. Генерация: `python3 gen_elevenlabs.py f` и `... m`.

## breath

Сядьте поудобнее.

Поставьте стопы на пол.

Расслабьтесь. Спина ровная, плечи опущены, руки спокойно лежат на коленях.

Вдыхайте носом и медленно выдыхайте ртом.

Дышите мягко, не глубже, чем вам удобно.

Дышите вместе со мной.

## return

Золотая сфера и это спокойствие будут с вами весь день.

Когда будете готовы, не торопясь, откройте глаза.
