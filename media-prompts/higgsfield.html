Промпты для Higgsfield

16 роликов: кокон, дыхание и визуалы практик. Каждый — 10 секунд на чёрном фоне: сайт сам кладёт их поверх полёта в космосе и зацикливает. Начните с кокона: он открывает каждую практику.

Как делать один ролик

  1. Картинка. В Higgsfield откройте Image → модель Higgsfield Soul (если нет — Seedream или Nano Banana). Формат 16:9. Вставьте текст из «Шаг 1». Сгенерируйте 4 варианта и выберите лучший: фигура без лица, чёрный фон, ничего лишнего.
  2. Видео. Нажмите на картинку → Animate / Create Video (image-to-video). Модель Kling 2.5 Turbo (лучше всего держит плавное движение). Если есть кредиты — Veo 3 или Kling 2.1 Master для максимального качества.
  3. Настройки видео: длительность 10 с, качество 1080p, камера Static / без движения, звук выключен. В поле промпта — текст из «Шаг 2». В поле Negative prompt (если есть) — строка ниже.
  4. Проверка: нет мерцания и резких вспышек, фигура не искажается, фон остаётся чёрным. Если плохо — сгенерируйте ещё раз с тем же промптом.
  5. Скачайте MP4 и переименуйте по имени файла из карточки (например, cocoon.mp4). Присылайте сюда в чат по 1–3 файла. Остальное сделаю я: сожму, сделаю бесшовную петлю и версию для телефона и подключу к практике.
Negative prompt — одинаковый для всех роликов
face, facial features, eyes, text, letters, logo, watermark, extra limbs, distorted anatomy, fast motion, flicker, strobe, flashing lights, camera shake, cartoon, low quality

Для телефона по желанию: тот же промпт в формате 9:16, имя с окончанием -m (например, cocoon-m.mp4). Если не сделаете — сайт сам обрежет горизонтальный ролик по центру.
